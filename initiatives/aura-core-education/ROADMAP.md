# Aura-Core Education Pilot Roadmap

## Phase 0 — Concept and governance

- Preserve product names, authorship, and dated concept records.
- Define the intended age groups and learning outcomes.
- Establish parent, educator, mentor, and operator roles.
- Complete child-safety, privacy, moderation, and data-retention reviews.
- Define what Aura may automate and what always requires a human.

## Phase 1 — Discord-only curriculum pilot

- Create a private test category in the existing Discord server.
- Use adult testers or a controlled educator cohort first.
- Register a least-privilege Aura education bot.
- Publish five text-based coding missions.
- Use GitHub templates or browser sandboxes for project work.
- Measure mission completion, help requests, moderation load, and learner comprehension.

## Phase 2 — Web learning workshop

- Build a controller-friendly web application.
- Add visual block coding with generated JavaScript or Python views.
- Add authenticated project storage and isolated test execution.
- Connect Discord commands to the Aura Education Gateway.
- Add educator review and private project galleries.

## Phase 3 — Game prototype

- Build a small game world containing coding missions.
- Support keyboard, touch, and standard controllers.
- Keep AI inference and code execution server-side.
- Add cooperative missions with role-based communication controls.

## Phase 4 — Platform partnerships

- Prepare a working educational prototype and safety documentation.
- Evaluate official Xbox and PlayStation developer programs.
- Submit only through approved platform-development and publishing pathways.
- Do not use retail consoles as unauthorized servers or background compute nodes.

## Initial success measures

- Learners can explain the code they submitted.
- Projects execute only inside isolated environments.
- No learner can reach infrastructure secrets or deployment controls.
- Educators can review progress without collecting unnecessary personal data.
- Moderation and safety reports have clear human ownership.
- The program produces reusable projects, not only chatbot conversations.

## First implementation backlog

1. Discord server role and channel specification.
2. Aura education bot command schema.
3. Mission format and five starter missions.
4. Parent/educator consent and participation flow.
5. Project submission schema.
6. Sandbox execution threat model.
7. Moderation and incident-response runbook.
8. Web workshop prototype.
9. Pilot evaluation report.
10. Official console-platform feasibility review.
