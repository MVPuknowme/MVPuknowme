# Coding Mission Template

## Mission metadata

- **Mission ID:**
- **Title:**
- **Recommended level:** beginner / intermediate / advanced
- **Estimated session length:**
- **Supported input:** blocks / JavaScript / Python
- **Collaboration mode:** solo / team
- **Adult review required:** yes / no

## Learning objectives

State what the learner should understand or be able to explain after completing the mission.

## Scenario

Describe the game, application, or problem in age-appropriate language.

## Build requirements

List the behaviors the learner must implement. Requirements should test understanding rather than reward copying a complete answer.

## Safety boundaries

Specify prohibited data, external connections, packages, file access, and communication behavior.

## Starter materials

Provide approved assets, sample data, scaffolding, and documentation links.

## Aura tutor behavior

Aura may:

- explain relevant concepts;
- ask guiding questions;
- identify the location and type of an error;
- demonstrate a smaller unrelated example;
- suggest a next debugging step.

Aura should not immediately provide the entire completed project unless an educator explicitly changes the assistance mode.

## Validation

Define deterministic checks for correctness, resource use, prohibited behavior, and expected output.

## Reflection

Ask the learner to explain:

1. what the project does;
2. which part was hardest;
3. how they debugged it;
4. what they would improve;
5. one safety or privacy decision they made.

## Submission

A submission should contain project files, validation results, a learner explanation, and the approving reviewer when review is required.
