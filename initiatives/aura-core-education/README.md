# Aura-Core Education

**Working concept:** Aura Forge — a safe, game-centered learning environment where young people learn coding, app creation, AI literacy, and collaborative problem-solving through Discord-guided missions and controller-friendly experiences.

## Purpose

Aura-Core Education extends the Aura-Core™ and SKYGRID concepts into an educational program. It does not turn consumer consoles into unauthorized background compute nodes. Xbox, PlayStation, PC, browser, and mobile devices are treated as approved learning clients. AI inference, code execution, validation, moderation, and storage remain inside controlled services.

## Core experience

1. A learner joins an approved Discord classroom or club.
2. Aura presents a guided mission.
3. The learner builds logic using blocks, scripts, or templates.
4. Code runs inside an isolated sandbox.
5. Aura explains errors without completing the entire assignment for the learner.
6. The learner publishes to a private project gallery after review.
7. Parents, educators, or program operators can review progress and safety events.

## Initial learning missions

- Program a robot through a maze.
- Create a weather and emergency-alert application.
- Build a two-player platform game.
- Design a SKYGRID-style routing simulation.
- Train a small, bounded classifier using approved sample data.
- Convert visual blocks into readable JavaScript or Python.
