# Starter Mission Set

## Maze Runner

Teach sequencing, conditions, loops, and debugging by guiding a robot through a maze with limited moves.

## Signal Relay

Build a simplified emergency-message router that classifies a message, validates required fields, and sends it to the correct simulated destination.

## Weather Watch

Use approved sample weather data to create a small dashboard that identifies hazardous conditions without collecting a learner's precise location.

## Cooperative Platformer

Program two characters with different abilities so a pair of learners must coordinate logic to complete a level.

## Friendly Classifier

Train or configure a bounded classifier using a small approved dataset, then examine mistakes and discuss why AI predictions require human judgment.

## App Builder

Create a simple useful application, such as a homework timer, reading tracker, accessibility reminder, or classroom resource finder, then explain the data it stores and why.
